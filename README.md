# ONG Mãos que Transformam

Aplicação web institucional para apresentar a missão e os projetos da ONG, com navegação para as iniciativas e para a página de cadastro.

## Estrutura

- `html/`: páginas HTML, incluindo a entrada da aplicação.
- `css/`: folha de estilos.
- `imagens/`: imagens utilizadas no projeto.
- `js/`: módulos JavaScript para navegação e comportamento da aplicação.

## Execução local

Com Python 3 instalado, execute na raiz do projeto:

```powershell
py -m http.server 8000
```

Depois, acesse <http://localhost:8000/html/> no navegador.

## Versionamento

O projeto utiliza GitFlow: `main` para versões estáveis, `develop` para desenvolvimento contínuo, `feature/*` para novas funcionalidades e `hotfix/*` para correções urgentes.
